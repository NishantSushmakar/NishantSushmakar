### 🚀 Featured work

Three agent patterns in one app: a basic chatbot, a **ReAct chatbot** with Tavily web search, and a multi-node **AI news aggregator pipeline** (fetch → summarize → persist).

**✍️ [blog-generation-agent](https://github.com/NishantSushmakar/blog-generation-agent)** · `LangGraph` · `FastAPI` · `LangSmith`
Deployable blog-generation agent with **conditional routing** for Hindi / French translation, Pydantic structured outputs, and LangSmith tracing. Configured for LangGraph Platform.

LGBM classifiers trained under fairness constraints and **differential privacy (ε=0.5)**, with a full evaluation pipeline comparing baseline / fair / private / fair+private variants — exactly the kind of work the EU AI Act asks for.

**🌊 [Carbon-Aware Image Segmentation](https://github.com/NishantSushmakar/Data-Capstone-Challenge)** · `EfficientNet` · `codecarbon` · `Explainability`
Coral-bleaching segmentation models compared not just by accuracy but by **energy and carbon footprint** via `codecarbon` instrumentation, plus prediction-level explainability.
